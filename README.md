# Productly - Product Explorer

A responsive product discovery application built with React, TypeScript,
Vite, and CSS.

## Features

- Browse product cards with images, names, prices, and categories.
- Search products by name.
- Filter products by category.
- Sort products by price from low to high.
- Display an empty state when no products match.
- Responsive layout for mobile, tablet, and desktop.
- Reusable React components with TypeScript interfaces.

## Tech Stack

- React
- TypeScript
- CSS
- Vite

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL shown in your terminal.

## Build for Production

Run:

npm run build

To preview the production build:

npm run preview

## Project Structure

- src/components: Reusable UI components
- src/data: Sample product data
- src/types: TypeScript types
- src/App.tsx: Search, filtering, sorting, and application layout
- src/App.css: Responsive component styling
- src/index.css: Global styles

## Notes

Product data is stored locally in the project. Product images are loaded
from Unsplash and require an internet connection.
